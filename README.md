Developed an I2C to APB Bridge to enable communication between I2C and APB peripherals. The project involved designing and implementing an I2C Master to manage SCL, SDA, start/stop conditions, and address/data transfers, while the I2C Slave interfaced with the APB bus for read/write operations. The design efficiently bridged the serial nature of I2C with the parallel structure of the APB interface, ensuring seamless data transfer and optimized performance.
